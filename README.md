# ПР10. Ответы на контрольные вопросы

1. это озночает что после создание string, его содержимое нельзя изменить. метод ToUpper() не меняет исходную строку а возвращает новую строку с верхним регистром поэтому если никуда её не сохранить, то новую строку нельзя будет использовать а исходный text останется без изменений.
2. text[index] - получим символ строки (char) который находится по указанному индексу. Length - кол-во символов в строке.
3. Split возвращает массив строк string[].
4. string - неизменяемый тип, при + создается новая строка в которую копируется сожержимое исходной + новое содержимое. при большом кол-ве таких + это все может работать не эффективно. StringBuilder предназначен для многократного изменения строки поэтому он удобнее и эффективнее.
5. Append - изменяет содержимое самого sb, когда ToUpper возвращает новую строку.
6. value - значение, 10 - ширина, N2 - запись с двумя знаками после запятой и разделением тысяч.
7. N2 разделяет разряды когда F2 просто записывает с двумя знаками после запятой.
8. sb не создает каждый раз новуюб строку поэтому он удобнее и эффективнее.
